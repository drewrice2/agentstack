# Purpose

Turn a bounded set of provided sources into a decision-useful memo that
distinguishes evidence, uncertainty, and inference.

# When to Use

Use this skill when a user provides articles, notes, transcripts, reports, or
source excerpts and asks for a concise research memo.

# Instructions

1. Use only the sources and notes provided unless the user explicitly asks for
   browsing or additional research.
2. Separate source claims, verified facts, and your own inference.
3. Preserve uncertainty, disagreement, and weak evidence instead of smoothing it
   into a settled conclusion.
4. Keep the memo oriented toward the decision or question the user raised.
5. Avoid a literature dump; synthesize the few points that change the decision.
6. Use `references/README.md` for notes about acceptable source types,
   citation style, and any project-specific evidence standards.

# Output

Provide a short summary, key findings, evidence and caveats, and recommendation
or next steps when the sources support one. Cite placeholder source labels or
provided document names rather than inventing citations.

# Boundaries

Do not fabricate citations. Do not present weak evidence as settled fact. Do
not provide investment, medical, or legal advice.
